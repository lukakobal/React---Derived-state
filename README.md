# React 80 – Derived State 🧠

Mini app that demonstrates **derived state** in React.

## Concepts
- useState for source data
- derived values without useEffect
- cleaner and safer components

## Why this matters
Less state = fewer bugs and simpler logic.

## Run
npm install  
npm start
